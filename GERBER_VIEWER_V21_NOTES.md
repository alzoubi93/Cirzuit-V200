# Gerber Viewer V21

## Improvements
- Added parsing for active Gerber aperture transformations `LM`, `LR`, and `LS`.
- Applies mirror, scale, and rotation to geometry generated by a block aperture at each flash location.
- Scales imported block track widths and pad dimensions, and transforms zone boundaries, zone holes, and outline segments consistently.
- Added regression tests for rotated/scaled and mirrored block aperture flashes.

## Remaining limitations
- Clear-polarity (`LPC`) block apertures are still not composited as ordered Boolean image operations.
- Nested block apertures and full transformation semantics for every aperture type are not fully implemented.
- The official Ucamco Gerber 2026.05 test package has not been run in this environment; this change does not claim full specification compliance.
- The project test/build commands have not been run because project dependencies are not installed in the editing environment.
